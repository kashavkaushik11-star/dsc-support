DSC Remote Support

If a written guide does not solve your issue, you can ask about a remote assistance session for Windows setup, token drivers, browser configuration, or signing utility troubleshooting.

Request Remote Support ↗
Important: A remote session is only arranged after you agree to the scope and any charges. Do not install remote-access software from an unverified link or share an unattended-access code.

How it works

1. Tell us the problem

Send the exact error message, Windows version, token brand/model if known, and the portal or signing utility name. Hide personal information in screenshots.

2. Confirm scope and cost

We will discuss what needs checking, whether remote assistance is suitable, and any applicable fee before you decide to proceed.

3. Approve the session

Use an agreed, trusted remote-support method. You must initiate or approve the connection and stay present during the session.

4. Review and disconnect

Watch the actions being taken, ask questions, and end the session when finished. Remove temporary access or disable unattended access afterwards.

What to prepare

  • Windows 10/11 version and the exact error text.
  • Token manufacturer/model, if visible.
  • Portal name and signing utility name/version.
  • Steps already tried and when the error occurs.

Security rules — please read

  • Never share your DSC PIN, OTP, private key, account password, or certificate files in chat.
  • Enter the DSC PIN yourself, locally, only when you understand and approve the signing action.
  • Do not let anyone sign, submit, or authorize a document on your behalf. Review every document yourself.
  • Close banking, email, and unrelated personal windows before a session; do not expose unrelated accounts or files.
  • Do not permit unattended access. End the session and revoke temporary access when the work is done.
  • If anything feels suspicious, disconnect immediately.
