DSC USB Token Not Detected in Windows 10/11?

Try these safe checks in order before reinstalling software or changing browser settings.

If your Digital Signature Certificate (DSC) USB token is not appearing in a signing utility or portal, the cause may be the USB connection, a missing or incompatible driver, a stopped signing service, or portal-specific requirements. Work through the checks below one at a time.

A laptop setup for checking token and signing software compatibility.

Security first: Never share your DSC token PIN, OTP, private key, or account password. Download drivers only from the token manufacturer or your certificate provider's official source.

1. Check the USB connection

  • Remove the token safely and reconnect it firmly.
  • Try another USB port directly on the computer; avoid hubs and extension cables for this test.
  • If possible, test the token on another trusted computer. Do not format or initialize the token.

Try a direct USB connection and check whether Windows responds.

2. Check Windows Device Manager

  1. Press Windows + X and open Device Manager.
  2. Look under Smart card readers, Universal Serial Bus controllers, and Other devices.
  3. Reconnect the token and watch for a new device or a yellow warning symbol.
  4. If it appears as an unknown device, note the displayed name or error before changing anything.
What the result can mean
  • No change at all: test another USB port or computer.
  • Unknown device / warning icon: check the correct manufacturer driver.
  • Device appears normally but portal cannot find it: continue to the signing utility and browser checks.

3. Install the correct token driver

Token drivers are not universal. Identify the token brand and model from its label or the provider's paperwork, then obtain the compatible Windows driver from the official manufacturer or certificate provider. Check whether the package supports Windows 10/11 and your system architecture.

Follow the installer instructions. Restart Windows if requested, reconnect the token, and check Device Manager again. Avoid unofficial driver-download sites and do not install multiple random driver packages to see what works.

Use the driver intended for your exact token model rather than a generic download.

4. Check the signing utility and browser

  • Confirm that the portal's required signing utility is installed and running, if applicable.
  • Use the portal's official instructions to check browser support and any required extension or service.
  • Close and reopen the browser after starting the utility. Test again in a supported browser.
  • If the portal reports a specific error, record the exact message and the time it occurred.

5. If it still does not work

Token not shown in Windows

Compare another USB port and another computer, then contact the token manufacturer if it remains undetected.

Token shown, portal fails

Check the signing utility, portal requirements, browser support, and certificate validity with the provider.

Frequently asked questions

Will reinstalling the driver always fix the problem?

No. The issue may be the USB port, token hardware, signing utility, browser, or portal configuration. Identify where the token stops appearing before reinstalling software.

Can I share a screenshot for help?

Yes, but hide your name, certificate serial number, PAN, email, token PIN, and any other sensitive information first.

Is DSC Support Desk an official government portal?

No. This site provides independent technical guidance. For certificate issuance, revocation, and provider-specific issues, contact your Certifying Authority or token provider.

Need help with your exact error?

Send the token brand/model, Windows version, portal name, and exact error text. Do not send your PIN or private certificate files.
