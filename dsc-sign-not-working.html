DSC Sign Not Working: Common Errors and Safe Fixes

Diagnose common digital signature failures by checking token detection, certificate validity, signing utility, browser compatibility, and portal requirements.

Security first: Use official CA, token manufacturer, or portal instructions. Never share your DSC PIN, OTP, private key, or account password.

If a DSC signature fails, avoid repeatedly reinstalling software without identifying the stage where the process stops. The problem may be hardware detection, certificate validity, a local signing utility, portal permissions, or a document-specific rule.

1. Identify the exact failure stage

  • Token is not visible: check the USB connection and Device Manager.
  • Certificate is missing: check the official token manager and certificate validity.
  • Portal cannot connect to a service: check the portal-required signing utility and whether it is running.
  • Certificate rejected: read the exact error and check validity, revocation, certificate type, and account registration with the relevant provider.
  • Only one document fails: check the portal's document format and workflow requirements.

2. Check the token and driver

Connect the token directly to a working USB port and check Windows Device Manager. Confirm that the driver matches the token model and Windows version. Use the driver installation guide if needed.

3. Check certificate validity and selection

Use the official token utility or certificate viewer to confirm the expected certificate is present and within its validity period. If the portal reports expiry, revocation, or trust issues, contact the CA rather than bypassing validation.

4. Check signing utility and browser

Use only the utility named by the target portal. Confirm it is installed and running, then follow the portal's current browser compatibility instructions. Do not open random ports, disable security software, or install unofficial certificate bundles.

5. Verify before signing

Make sure you are signed in to the correct account and have selected the intended certificate. Read the document or transaction details carefully. Do not authorize a signature if the displayed details are unexpected.

What to tell support

Share the exact error, portal name, Windows/browser versions, token model, whether Windows detects the token, and whether the certificate appears in the token manager. Redact personal information and never disclose secrets.

Frequently asked questions

Will reinstalling the driver always fix DSC signing?

No. The failure can be in the certificate, utility, browser, portal account, or document workflow.

Can I bypass a certificate warning?

No. Verify the issue with the CA or official portal helpdesk before proceeding.

Need help with your exact issue?

Share the token model, Windows version, portal name, and exact error text. Hide personal details in screenshots. Never send your PIN, OTP, private key, or certificate files.
